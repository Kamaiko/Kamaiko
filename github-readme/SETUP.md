# GitHub Readme Stats Setup

## Liens directs
- Vercel Dashboard: https://vercel.com/dashboard
- Vercel Env Variables: https://vercel.com/kamaikos-projects/github-readme-stats/settings/environment-variables
- GitHub Tokens: https://github.com/settings/tokens
- Fork Repo: https://github.com/Kamaiko/github-readme-stats
- Stats URL: https://github-readme-stats-mauve-one-58.vercel.app

## Config
- Token name: readme-stats
- Variable Vercel: PAT_1

## Si stats cassees
1. https://github.com/settings/tokens → cliquer sur "readme-stats" → Regenerate
2. Copier le nouveau token
3. https://vercel.com/kamaikos-projects/github-readme-stats/settings/environment-variables → update PAT_1
4. https://vercel.com/kamaikos-projects/github-readme-stats/deployments → Redeploy (sans cache)

## Claude
Fork de github-readme-stats sur Vercel. PAT pour compter repos prives. Stats cassees = token expire.
